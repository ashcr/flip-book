# B2B book preview

Two production PDFs, each on its own page.

- Design A: `design-a/`
- Design B: `design-b/`

The page turn uses [StPageFlip](https://github.com/Nodlik/StPageFlip) (MIT). The cover opens by itself, like a closed book. After that, desktop shows a two-page spread and a phone shows one page. Drag a corner, swipe, or use the arrows to turn the page.

Open the site through GitHub Pages. Opening the HTML files directly will not load the PDFs.
