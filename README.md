# B2B book preview

Two production PDFs, each on its own page.

- Design A: `design-a/`
- Design B: `design-b/`

On screens 800px and narrower the book shows one page. Wider screens show a two-page spread. Use the arrows, swipe, or the left and right arrow keys to turn pages.

Open the site through GitHub Pages. Opening the HTML files directly will not load the PDFs.
