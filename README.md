# 3D Flip Book preview

Static preview of [iberezansky/flip-book-jquery](https://github.com/iberezansky/flip-book-jquery) (GPL-2.0) so it can be opened on GitHub Pages from a phone or a desktop.

The sample pages are `books/theKingIsBlack/` from [flip-book-jquery-example](https://github.com/iberezansky/flip-book-jquery-example).

Open the site through a web server or GitHub Pages. Opening `index.html` as a file will not load the book.

On screens 800px and narrower the book starts in single-page mode. Wider screens show the two-page spread. Drag a page corner, or use the arrows, to turn pages.

The public build shows up to 10 pages. This sample magazine is 10 pages.
